# 🚗 Car Rental System

This project is a car rental platform where users can **rent a car**, **see nearby Avis offices on the map**, **log in as a user** and **search for a car by filtering**.

🔹 **There are 4 pages in total:**
1. **Login Page** – Login can be done **manually via email or using OAuth with Google.**
2. **Register Page** – User can upload **photos while registering.**
3. **Home** – **Car search & Avis branches map integration.**
4. **Search Results** – Vehicles that match the **filters selected by the user are listed.**

-There is a problem with the billing part of the doodle developers account, so it does not show the map correctly and gives a "billing" error even though the key is given.
